🛡 DEFENSAS ACTIVAS EN ESTE SERVIDOR
✓ TLS/HTTPS: todo el tráfico va cifrado. El atacante solo ve bytes ilegibles.
✓ HSTS: el navegador nunca usará HTTP para este dominio, ni aunque el atacante lo intente (SSL Stripping).
✓ Certificado TLS: si el atacante intercepta la conexión, el navegador detecta que el certificado no corresponde y bloquea la comunicación.
✓ CSP + X-Frame-Options: previene inyección de scripts y clickjacking.
